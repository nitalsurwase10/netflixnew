# Netflix Insights

A Streamlit dashboard for viewing and revenue data.

## Run locally

1. Install dependencies with `pip install -r requirements.txt`.
2. Place your private dataset beside `netflixproject.py` as `Netflix.csv.csv`, `netflix.csv`, or `Netflix.csv`.
3. Start the app with `streamlit run netflixproject.py`.

The customer dataset is intentionally not included in this repository. The CSV needs `Customer_ID`, `Region`, `Subscription_Plan`, `Category`, `Watch_Date`, `Monthly_Revenue`, `Rating`, `Watch_Time_Minutes`, and `Watch_Count` columns.
